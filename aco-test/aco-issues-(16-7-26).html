ACO Transcription Issues Report

Issues Observed During ACO Transcription Testing — 16/7/26

Executive Summary

Recent testing of the ACO transcription system revealed critical anomalies around missing content, hallucinated text, silence-handling failures, and unexpected language code-switching. Each issue below includes supporting screenshots where available.

Identified Issues

Issue 1

Deletion Errors (Dropped Content)

The model exhibits a high word deletion rate, completely omitting spoken sentences and lines from the final transcript.

Reference Link:
https://aco.digitaltribe.cloud/meetings/dd418c56-1a59-4fe8-ab92-1e0291a7e3dc

Issue 2

Insertion Errors (Phantom Content)

The system generates non-existent text segments and phrases that are entirely absent from the source audio.

Example Output Generated:

“قانون کی قیمت کرنے کے لئے قیمت کرنے کے لئے قانون کی مدد ہے۔ یہ مدد ہے کہ یہ قانون کی قیمت کرنے کے لئے”

Reference Link:
https://aco.digitaltribe.cloud/meetings/e5deb381-1646-4b46-abcc-ee9998de129b

Issue 3

Voice Activity Detection (VAD) & Padding Artifacts

Brief pauses or periods of silence trigger loop hallucinations, causing the model to incorrectly inject repetitive boilerplate phrases (e.g., transcribing silence repeatedly as "Thank you., you").

Issue 4

Language Model Code-Switching Hallucinations

The model suffers from cross-lingual hallucinations, abruptly generating Urdu text outputs during periods of continuous, monolingual English speech.
