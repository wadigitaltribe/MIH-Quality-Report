Suggestions to reduce WER

  • Disable translation behaviour: set the ASR task to 'transcribe' (not 'translate'), or instruct the model to output verbatim speech only, in the original language mix.
  • Post-process: drop sentences that duplicate the meaning of the immediately preceding segment in another language (near-duplicate detection before scoring or delivery).
  • Improve acoustic robustness for mishears: cleaner audio (less noise, better mic), a domain lexicon / hotword list with the expected vocabulary, and a spelling-correction post-processing pass for known confusion pairs.
  • Check for audio dropouts / aggressive VAD trimming causing missed words; lower the VAD threshold or use overlapping chunks.

Issues

  1. Insertion Runs: The transcript contains massive, repetitive insertion runs (up to 100+ words) that inflate the WER significantly.
  2. Semantic Confusion: The model often substitutes words with semantically unrelated terms (e.g., "nod" → "us", "drawing" → "healthy."), indicating a lack of lexical understanding.
  3. Deletion of Function Words: Frequent deletion of small, high-frequency words (e.g., "the", "and", "is") disrupts sentence structure and grammar.

Suggestions

  1. Audio Pre-processing: Apply noise reduction and audio normalization to improve signal clarity, which helps the model distinguish phonemes better.
  2. VAD Configuration: Adjust the Voice Activity Detection (VAD) sensitivity to prevent the model from inserting silence or incorrectly segmenting speech, which reduces insertion runs.
  3. Language Model Tuning: Configure the language model to prioritize the dominant language of the specific audio segment or apply a "language switch" penalty to discourage mixing.
  4. Post-Processing: Implement a rule-based post-processor to remove repetitive insertion runs and correct common code-switching substitutions.
