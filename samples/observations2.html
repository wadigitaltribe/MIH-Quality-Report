MIH Transcription Observations Report

Detailed Analysis of System and Bot Performance Issues

Executive Summary

This report compiles critical performance and behavior metrics observed during recent live testing. While some elements behave normally, key systemic bugs involving bot response mechanics, data persistence, translation logic, and rendering latency have been identified below.

Identified Issues

1. Automatic Deletion of Temporary Transcription Content

The system intermittently captures transcription segments, but fails to persist them to the timeline long-term.

  • Observation: Transcription for an active meeting was successfully received and displayed for 2 to 4 seconds, but was automatically purged/removed from the end-state view.

2. Bot Unresponsiveness / No Transcription Generation

A major blocker occurs when launching new sessions where the processing bot joins but remains passive.

  • Observation: Transcription is entirely missing upon creating a meeting. Even though the bot (Zazu) is visibly present inside the meeting room, it remains completely unresponsive.
  • Affected Session: https://mih.pda.gov.pk/meetings/f1bf3fbf-8785-4749-8977-cf6c8f308950

3. Excessive Generation Latency

Processing pipelines are experiencing notable delays, impacting the real-time or near-real-time user experience.

  • Observation: Transcription processing/generation is taking an excessive amount of time to finalize and display.

4. Incorrect Translation in Mixed Language Audio

The model defaults to translation rather than literal code-switching transcription when multi-language input is present.

  • Observation: During mixed-language (Urdu-English) conversations, lines spoken natively in Urdu were erroneously translated into English instead of being transcribed directly as spoken Urdu.

Gentle Note

These observations highlight severe functional gaps regarding data retention, processing speed, and localized language handling. We will run secondary evaluations on these specific sessions to pinpoint whether these anomalies stem from engine processing errors or API timeout thresholds.
